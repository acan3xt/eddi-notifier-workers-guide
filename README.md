# eddi-notifier | エッヂャーアラート

エッヂ掲示板および一部の5ch板の新着スレッドを監視し、指定したキーワードに一致したスレッドをWeb PushまたはDiscordへ通知するサービスです。

Google Apps Script版の[acan3xt/eddi-notifier-gas](https://github.com/acan3xt/eddi-notifier-gas)を、Cloudflare Workers向けに移植・拡張しています。

## 主な機能

- エッヂおよび一部の5ch板を定期監視
- 通知キーワードのOR検索・AND検索
- 除外キーワードの設定
- 最低レス数を指定した通知
- Web Pushによるブラウザ通知
- Discord Webhookによる通知
- Web Pushのみ、Discordのみ、または両方への通知
- 監視対象板の個別選択
- エッヂの通常タイトル・記者ID付きタイトルの選択
- オリジナルURL・kyodemo・両方から通知リンクを選択
- Web Push通知先を最大5台まで登録
- 通知先端末の一時停止、再開、テスト通知、削除
- 20桁のアカウント番号、またはユーザー名とパスワードで利用
- 設定変更の未保存表示
- ライト・ダーク・自動テーマ

## 対応掲示板

現在、以下の掲示板に対応しています。

- エッヂ
- 5ch 嫌儲
- 5ch ニュー速VIP
- 5ch なんJ
- 5ch なんG

## 使い方

### 1. アカウントを作成する

トップページの「新規登録」から、次のどちらかを選びます。

#### アカウント番号ですぐに始める

CAPTCHAを確認すると、20桁のアカウント番号が発行されます。

アカウント番号はログインに必要な認証情報です。サーバーにはハッシュ化して保存されるため、発行画面を閉じると同じ番号を再表示・復旧できません。必ず安全な場所に保存してください。

ログイン中であれば、設定画面からアカウント番号を再発行できます。再発行後は以前の番号が無効になり、ほかの端末からもログアウトします。

#### ユーザー名で新規登録

ユーザー名とパスワードを入力し、CAPTCHAを確認して登録します。

- ユーザー名：3〜32文字
- 使用可能文字：半角英数字と `_` `-` `.` `@` `+`
- パスワード：8〜128文字
- パスワードの文字種制限：なし

### 2. 通知先を設定する

通知先として、Web PushとDiscord Webhookを利用できます。

#### Web Push通知

Web Pushは、WebサイトからスマートフォンやPCのブラウザへ通知を送る仕組みです。

専用アプリやDiscordを使わなくても、登録した端末の通知欄へ新着スレッドの通知を表示できます。通知を受け取るには、使用しているブラウザで通知を許可し、その端末をeddi-notifierへ登録する必要があります。

「通知先設定」から「Web Push通知」を開きます。

1. 端末名を入力する
2. 「この端末で通知を有効にする」を押す
3. ブラウザに表示される通知許可を承認する
4. 登録済み端末の一覧に追加されたことを確認する
5. 必要に応じて「テスト通知」を押し、通知が届くことを確認する

端末名は、自分で見分けやすい名前にできます。

```text
自宅PC
iPhone
Androidスマホ
```

Web Push通知先は最大5台まで登録できます。同じアカウントで、スマートフォンとPCの両方へ通知することもできます。

登録済み端末では、次の操作ができます。

- 通知を一時的にOFFにする
- 通知をONに戻す
- テスト通知を送る
- 登録を削除する
- 最終成功日時などの端末情報を確認する

ブラウザで通知を拒否した場合は、ブラウザのサイト設定から通知を許可し直してください。一度拒否すると、eddi-notifierのボタンを押すだけでは再び許可画面が表示されない場合があります。

##### iPhone・iPadで利用する場合

iPhone・iPadでは、Safariでeddi-notifierを開き、ホーム画面へWebアプリとして追加してから、追加されたアイコンを使ってサイトを開く必要があります。通常のSafariタブだけではWeb Pushを受け取れません。

正常に追加できた場合は `✓ Web Push対応ブラウザ` と表示されます。

詳しい追加方法はApple公式ガイドをご覧ください。

[iPhone・iPadでWebサイトをホーム画面に追加する方法（Apple公式）](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)

#### Discord Webhook通知

通知を受け取りたいDiscordチャンネルで、Webhook URLを作成します。

1. Discordの「サーバー設定」または「チャンネルの編集」を開く
2. 「連携サービス」を開く
3. 「ウェブフック」を開く
4. Webhookを作成する
5. 「ウェブフックURLをコピー」を押す
6. eddi-notifierの「Discord Webhook URL」に貼り付ける

詳しい作成方法はDiscord公式ガイドをご覧ください。

[Discord Webhook URLの取得方法（Discord公式）](https://support.discord.com/hc/ja/articles/228383668-%E3%82%A6%E3%82%A7%E3%83%96%E3%83%95%E3%83%83%E3%82%AF%E3%81%AE%E3%81%94%E7%B4%B9%E4%BB%8B)



保存済みのWebhook URLは、設定画面から削除できます。削除するとDiscord通知もOFFになります。

### 3. 通知キーワードを設定する

通知したいスレッドタイトルのキーワードを入力します。英字の大文字・小文字は区別しません。

通知キーワードは全体で500文字まで入力できます。

#### OR検索

改行ごとに別の条件として扱います。いずれかの行に一致すると通知します。

```text
野球
サッカー
```

この例では、「野球」または「サッカー」を含むタイトルが通知対象です。

#### AND検索

同じ行をカンマ（`,` または `、`）で区切ると、その行のすべてのキーワードを含む場合に通知します。

```text
猫,犬
ドラゴン、ザウルス
```

この例では、次のどちらかに一致すると通知します。

- 「猫」と「犬」の両方を含む
- 「ドラゴン」と「ザウルス」の両方を含む

#### 最低レス数を指定する

行末に `@整数` を付けると、そのレス数以上になった時点で通知します。

```text
野球@100
猫,犬@50
```

- `野球@100`：タイトルに「野球」を含み、レス数が100以上で通知
- `猫,犬@50`：「猫」と「犬」の両方を含み、レス数が50以上で通知

指定できるレス数は `0〜1000` です。

- 指定なし、`@0`、`@1`：スレッドを見つけた時点で通知
- `@2` 以上：指定レス数へ到達した時点で通知
- `@1001` など範囲外の値：保存不可
- 小数や文字付きの値：レス数条件ではなく通常のキーワードとして扱う
- 行の途中にある `@`：通常のキーワード文字として扱う

例：

```text
LAD@
CHC@@100
```

- `LAD@`：`LAD@` を通常のキーワードとして検索
- `CHC@@100`：`CHC@` を含み、レス数100以上で通知

同じスレッドが複数の条件に一致しても、通知は原則1回です。

#### 1文字のキーワード

- ひらがな・カタカナ・英数字を単独指定する場合は2文字以上必要
- 漢字・記号・絵文字は1文字でも使用可能
- AND検索の一部として使う場合は1文字でも使用可能
- `[` と `]` は単独1文字のキーワードとして使用不可

通知キーワードが空の場合、キーワード通知は送信されません。

### 4. 除外キーワードを設定する

通知したくないタイトルに含まれるキーワードを入力します。複数指定する場合は改行で区切ります。

```text
りんご
みかん
```

いずれか1つを含む場合は通知しません。

除外キーワードの判定は通知キーワードより優先されます。

除外キーワードは全体で100文字まで入力できます。

### 5. 監視対象を選ぶ

「監視する板」から、通知対象にする板を選択します。複数選択できます。

- エッヂ
- 5ch 嫌儲
- 5ch VIP
- 5ch なんJ
- 5ch なんG

エッヂでは、タイトル形式を次から選べます。

- 通常
- 記者ID付き

### 6. 通知リンクを選ぶ

通知に掲載するリンクを次から選べます。

- オリジナルURL
- kyodemo
- 両方

### 7. 通知方法を選ぶ

「通知方法」から、利用する通知方法を選びます。

- Web Push通知
- Discord通知

Web Pushのみ、Discordのみ、または両方を有効にできます。

Discord通知を有効にする場合は、Discord Webhook URLの設定が必要です。

### 8. 通知を有効にして保存する

「通知を有効にする」をONにし、「設定を保存」を押します。

通知方法を1つ以上選択していない場合、通知は有効になりません。

設定を変更すると、画面に「未保存の変更があります」と表示されます。保存前にページを閉じたりログアウトしたりすると、変更は反映されません。

### 9. テスト通知を送る

#### Web Push

登録済み端末の「テスト通知」を押します。

#### Discord

Discord Webhook URLを保存した状態で「テスト通知」を押します。

Discord通知が無効の場合は、有効にするか確認画面が表示される場合があります。

届かない場合は、次を確認してください。

- 通知全体が有効か
- 利用する通知方法が選択されているか
- 設定を保存したか
- Discord Webhook URLが正しいか
- Web Push端末が停止中や失効状態になっていないか
- ブラウザで通知が許可されているか
- iPhone・iPadではWebアプリとしてホーム画面に追加できているか

## 設定の変更

ログイン後、次の設定を変更できます。

- Discord Webhook URL
- Web Push通知先
- 通知キーワード
- 最低レス数
- 除外キーワード
- 監視対象板
- エッヂのタイトル形式
- 通知リンク
- 通知方法
- 通知全体のON・OFF

変更後は必ず「設定を保存」を押してください。

## Web Push通知先の管理

登録済み端末には、次の状態があります。

- 有効
- 停止中
- 一時エラー
- 失効
- 未確認

停止中の端末は、設定を残したまま通知だけ停止できます。

失効した端末や不要になった端末は削除してください。

## アカウント番号の再発行

番号式アカウントでログインしている場合、設定画面の「アカウント番号の再発行」から新しい番号を発行できます。

再発行すると、

- 現在の番号が無効になる
- ほかの端末からログアウトする
- 新しい番号は一度だけ表示される
- 再発行には一定の待機時間がある

という動作になります。

確認文字列として `アカウント番号を再発行` の入力とCAPTCHA確認が必要です。

## パスワードの変更

ユーザー名・パスワード式アカウントでは、ログイン後の「パスワード変更」から変更できます。

現在のパスワードと新しいパスワードを入力してください。

変更後はすべての端末からログアウトするため、新しいパスワードで再度ログインしてください。

## アカウントの削除

ログイン後の「アカウント削除」から削除できます。

ユーザー名・パスワード式アカウントでは、

- 現在のパスワード
- 確認文字列 `アカウントを削除`

が必要です。

番号式アカウントでは、確認文字列だけで削除できます。

アカウントに関する情報は完全に削除され、この操作は取り消せません。

## 表示テーマ

画面上部から、次のテーマを選べます。

- 自動
- ライト
- ダーク

「自動」はOSやブラウザの表示設定に連動します。

## 注意事項

本サービスは、エッヂ、5ch、Discord、kyodemo、Cloudflareが提供または運営する公式サービスではありません。

掲示板や外部サービスの障害、仕様変更、アクセス制限、通信状況などにより、通知の遅延、未達、またはサービス停止が発生する場合があります。

通知の完全性、即時性、継続的な提供は保証されません。

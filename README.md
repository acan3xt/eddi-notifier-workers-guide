# eddi-notifier | エッヂャーアラート 

[エッヂ掲示板](https://bbs.eddibb.cc/) および一部の5ch板の新着スレッドを監視し、指定したキーワードに一致したスレッドをDiscordへ通知するサービスです。

Google Apps Script版の[acan3xt/eddi-notifier-gas](https://github.com/acan3xt/eddi-notifier-gas)を、Cloudflare Workers向けに移植しました。

## URL

## <https://eddi-notifier.acanendo.workers.dev/>

## 特徴

- **エッヂ・5chの新着スレッドを自動監視**  
  対象の掲示板を1~2分間隔で取得し、新しく立ったスレッドを検出します。

- **キーワードに一致したスレッドをDiscordへ通知**  
  指定したキーワードをスレッドタイトルに含む場合、Discord Webhookを通じてDiscordのチャンネルへ通知します。

- **OR検索・AND検索に対応**  
  キーワードを改行するとOR検索、同じ行をカンマで区切るとAND検索として判定します。

- **除外キーワードを設定可能**  
  通知したくない内容を除外できます。除外キーワードは通知キーワードより優先して判定されます。

- **複数の掲示板を選択可能**  
  エッヂ、嫌儲、VIP、なんJ、なんGから監視対象を選択できます。

- **通知リンクの形式を選択可能**  
  オリジナルのURL、kyodemo、または両方を通知に掲載できます。

- **ユーザーごとに通知設定を保存**  
  アカウントを作成することで、Webhook、キーワード、監視対象などを個別に管理できます。

- **テスト通知に対応**  
  保存したWebhookへテスト通知を送り、実際に届くか確認できます。

## 対応掲示板

現在、以下の掲示板に対応しています。

- エッヂ
- 5ch なんG
- 5ch なんJ
- 5ch ニュー速VIP
- 5ch 嫌儲


## 使い方

### 1. アカウントを作成する

トップページの「新規登録」では、次の2つの方法から選べます。

#### アカウント番号ですぐに始める

CAPTCHAを確認後、20桁のアカウント番号が自動で発行され、すぐに通知設定を始められます。

アカウント番号はログインに必要な大切な認証情報です。サーバーにはハッシュ化して保存されるため、発行画面を閉じると再表示・復旧できません。必ず安全な場所に保存してください。

#### ユーザー名で新規登録

ユーザー名とパスワードを入力し、CAPTCHAを確認して登録します。

- ユーザー名：3〜32文字。半角英数字と `_` `-` `.` `@` `+` が使用できます
- パスワード：8〜128文字。文字種の制限はありません

登録後は、そのまま通知設定を始められます。
### 2. Discord Webhook URLを取得する

通知を受け取りたいDiscordサーバーかDiscordのチャンネルで、次の順に開きます。

1. 「サーバー設定/チャンネルの編集」を開く
2. 「連携サービス」を開く
3. 「ウェブフック」を開く
4. Webhookを作成し、「ウェブフックURLをコピー」を選ぶ

詳しくは[Discord公式のWebhook案内](https://support.discord.com/hc/ja/articles/228383668-%E3%82%A6%E3%82%A7%E3%83%96%E3%83%95%E3%83%83%E3%82%AF%E3%81%AE%E3%81%94%E7%B4%B9%E4%BB%8B)をご覧ください。

コピーしたURLを、eddi-notifierの「Discord Webhook URL」へ貼り付けます。

### 3. 通知キーワードを設定する

通知したいスレッドタイトルのキーワードを入力します。英字の大文字・小文字は区別しません。

#### OR検索

キーワードを改行すると、行ごとに別の条件として判定します。いずれかの行に一致すると通知します。

```text
野球
サッカー
```

この例では、「野球」または「サッカー」を含むタイトルが通知対象です。

#### AND検索

同じ行をカンマ（`,` または `、`）で区切ると、その行にあるすべてのキーワードを含むタイトルだけを通知します。

```text
猫,犬
ドラゴン、ザウルス
```

「猫」と「犬」の両方、または「ドラゴン」と「ザウルス」の両方を含むタイトルが通知対象です。

#### 1文字のキーワード

- ひらがな・カタカナ・英数字を単独で指定する場合は、2文字以上必要です
- 漢字・記号・絵文字は1文字でも使用できます
- ひらがな・カタカナ・英数字でも、AND検索に含める場合は1文字で使用できます（例：`a,英語`）
- `[` と `]` は1文字のキーワードとして使用できません

通知キーワードは全体で500文字まで入力できます。

通知キーワードが空の場合、キーワード通知は送信されません。

### 4. 除外キーワードを設定する

通知したくないタイトルに含まれるキーワードを入力します。複数指定する場合は改行で区切ります。

```text
りんご
みかん
```

除外キーワードはいずれか1つを含むと一致し、通知されません。除外判定は通知キーワードの判定より優先されます。

除外キーワードは全体で100文字まで入力できます。

### 5. 監視対象と通知形式を選ぶ

「監視する板」から通知対象を選択します。複数選択できます。

- エッヂ
- 5ch 嫌儲
- 5ch VIP
- 5ch なんJ
- 5ch なんG

エッヂでは、タイトル形式を「通常」または「記者ID付き」から選択できます。

通知に載せるリンクは、次の形式から選択できます。

- オリジナルURL
- kyodemo
- 両方

### 6. 通知を有効にして保存する

「Discord通知を有効にする」をオンにし、「設定を保存」を押します。

このスイッチがオフの場合、キーワード通知とテスト通知は送信されません。


### 7. テスト通知を送る

「テスト通知」を押し、Discordへ通知が届くことを確認します。テスト通知は60秒に1回まで送信できます。

届かない場合は、次の点を確認してください。

- 「Discord通知を有効にする」がオンになっているか
- 設定を保存したか
- Discord Webhook URLが正しいか
- Webhookを作成したDiscordチャンネルを確認しているか

## 設定の変更

ログインすると、保存済みのWebhook URL、キーワード、監視対象などを編集できます。変更後は必ず「設定を保存」を押してください。

画面上部では「ライト」「ダーク」「自動」から表示テーマを選択できます。

## パスワードの変更

ログイン後の「パスワード変更」から、現在のパスワードと新しいパスワードを入力します。

変更後はすべての端末からログアウトするため、新しいパスワードで再度ログインしてください。

## アカウントの削除

ログイン後の「アカウント削除」から削除できます。現在のパスワードと確認文字列 `アカウントを削除` の入力が必要です。

アカウントに関する情報は完全に削除され、この操作は取り消せません。
